# Simulation Controls

Keyboard controls:

| Key | Function | Description / Condition |
| :---: | :--- | :--- |
| **`C`** | Switch Capacitor Charges | Reverses the positive/negative poles of the deflection capacitors (`k3` and `k4`) before the particle reaches the gap (`particle.pos.x < gap.x`). |
| **`S`** | Toggle Symmetry Mode | Enables or disables the mirrored particle view and movement trail relative to the symmetry axis. |
| **`ESC`** | Exit | Closes the window and terminates the simulation. |
